# Cascade v0.1.0

First public library release, 2026-10-22. MIT licensed; requires .NET 10.

## Included

- `Wixely.Cascade.Core`: vector registers, instructions, and immutable modules.
- `Wixely.Cascade.Runtime`: validated CVM1 loading, reference and portable SIMD
  execution, fuel and memory limits, explicit host capabilities, reusable instances,
  and packed sequential batches.
- `Wixely.Cascade.Compiler`: typed language 0.3, deterministic optimization,
  register allocation and private spilling to CVM1 1.1. Unspilled kernels retain
  CVM1 1.0 compatibility.
- Source examples, scalar-checked demos, conformance tests, and benchmarks.

Download all three NuGet packages into a local feed and follow the
[library quickstart](https://github.com/Wixely/Cascade/blob/v0.1.0/docs/library-quickstart.md).
Packages contain managed libraries, not native standalone executables. No
NuGet.org listing is assumed. SHA256SUMS.txt covers the downloadable packages.

## Verification and limitations

Compiler and runtime suites previously passed Windows/Linux x64 managed and
NativeAOT execution (24 compiler cases, 33 conformance cases). The release
package consumer checks compile, execute, restart, batch, and spill round-trips
using only an isolated local package feed.

The API is early-stage. Integer kernels only; no floating point, GPU backend,
guest JIT, or general-purpose scripting. SIMD does not guarantee faster
end-to-end execution than native scalar code. Dispatch fusion is experimental
and disabled by default. Host imports must be bounded by the embedding host;
fuel cannot interrupt a blocking callback. No independent security audit is claimed.
